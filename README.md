Student Cafe Registration System
Description
A C++ application for managing student registrations at a cafe, allowing users to register students, search by ID, and display all registered students.

Features
Student Class
Attributes: ID, Name, Registration Time.
Methods: getId(), getName(), getRegistrationTime(), getFormattedRegistrationTime().
CafeRegistration Class
Manages student data and file operations.
Methods:
registerStudent()
searchStudentByID()
getAllStudents()
generateAllStudentsTable()
Main Function
Interactive menu for:
Registering students
Searching by ID
Displaying all students
Exiting the program
